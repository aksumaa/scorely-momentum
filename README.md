# Scorely Momentum

Scorely Premium Landing Page Redesign

Redesign the existing Scorely website into a premium, modern, high-converting IELTS preparation platform.

IMPORTANT:
Do NOT create a generic AI SaaS landing page.
Do NOT replace the existing Scorely product with an unrelated concept.
Do NOT invent fake features, fake statistics, fake testimonials, fake partnerships, fake exam scores, or fake user results.

Use the existing Scorely website and its real content as the primary product source of truth:
https://scorely.uz/

Preserve the existing product identity, Scorely name, logo concept, real features, and real messaging, but completely redesign the visual experience, UX structure, hierarchy, animations, spacing, typography, and interactions.

The goal is to make Scorely feel like a premium international EdTech product that could compete visually with top European and Asian education platforms.

The user should open the website and immediately understand:

"Scorely helps me prepare for IELTS, understand my weaknesses, practise all four skills, use AI guidance, and improve my target band."

The website should create enough visual impact and clarity that an IELTS student immediately wants to create an account and start a free exam/practice session.
